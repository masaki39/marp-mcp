## What's New in 1.6.0

### Academic Style: Layout Consolidation

Reduced the academic style layout count from 15 to 11 by merging redundant layouts, making it easier for LLMs to choose the right layout.

**Merged layouts:**

- **`comparison` → `two-column`**: Add `panelStyle: "comparison"` to get the left-gray / right-maroon contrast style for conventional vs. proposed comparisons. All panel params (`leftTitle`, `leftList`, `rightTitle`, `rightList`) are now required to prevent empty panels.
- **`figure-caption` → `image-center`**: Add `figNumber` (e.g. `"1"`, `"2a"`) to switch to figure-caption mode, which renders a `Fig. X.` label. The `source` attribution param is also available in this mode.
- **`results-table` removed**: Standard markdown table format (`table` layout) is more natural for LLMs. The `table` layout now accepts an optional `caption` param (e.g. `"Table 1: Results on benchmark dataset"`).
- **`sidebar` removed**: The `content` layout now accepts optional `sidebarTitle` and `sidebarItems` params. When provided, a sidebar panel is rendered on the right side — no need to switch layouts.

### New: Enum Validation for Layout Parameters

Layout parameters can now declare an `enum` constraint. Passing an invalid value returns a clear error message listing the allowed values. The `panelStyle` parameter in `two-column` is the first to use this (`"symmetric"` or `"comparison"`).
