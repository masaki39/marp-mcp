## What's Changed

### Bug Fixes

- **`export_slide`: marp binary resolution fixed** — Previously looked for `marp` in `node_modules/.bin` relative to `process.cwd()`, which fails in production since `@marp-team/marp-cli` is a dev dependency and `cwd` is not the package directory. Now uses `marp` from `PATH`. When not found, returns a clear error message: _"marp command not found. Install with: `npm install -g @marp-team/marp-cli`"_.

- **`generate_agenda`: idempotent — calling twice no longer duplicates agenda slides** — Previously, running `generate_agenda` on the same file twice would insert duplicate agenda slides before each section. Generated agenda slides are now marked with `<!-- agenda-generated -->` and removed at the start of each call.

- **`path-validator`: valid paths with `.` segments no longer rejected** — The traversal check compared `normalize(path)` against the original string, which incorrectly rejected legitimate paths containing `.` components (e.g. `/home/user/./slides.md`). The check now targets only `..` segments.

### Refactoring

- **`manage_slide`: removed duplicate `ensureAllSlidesHaveIds` helper** — The local function duplicated the exported `ensureAllSlideIds` from `slide-id.ts`. Now uses the shared utility directly.

- **`add_image_transition` / `generate_agenda`: frontmatter parsing unified to `gray-matter`** — Both tools previously split frontmatter with a custom parser then re-parsed with `gray-matter`. Now `gray-matter` handles the full parse in one step.
