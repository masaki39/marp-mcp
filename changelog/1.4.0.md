## What's Changed

### New Tools

- **`generate_agenda`** — Auto-generates an agenda slide from section slides (detected by `<!-- _class: {sectionClass} -->`).  
  Inserts the agenda immediately before the first section slide, adds numbered icons using icongr.am SVGs, and injects `transition: fade` plus view-transition CSS into frontmatter.  
  Section slides also receive matching white icons so the icon morphs between the agenda and each section via CSS View Transitions.  
  Visible in HTML export only.

- **`add_image_transition`** — Inserts a full-screen image slide (`<!-- _class: img-fullscreen -->`) before a specified slide (by slide ID) to create image morphing transitions.  
  The inserted slide uses an inline `<img>` element (not a CSS background) so `view-transition-name` applies to a real DOM node and the browser can animate the morph.  
  The morph name is prepended to the alt text of both images so `img[alt~="name"]` CSS targeting works on both slides.  
  `transition: fade` and required CSS (`section.img-fullscreen`, `img[alt~="name"]`) are automatically injected into frontmatter.  
  Visible in HTML export only.

### Breaking Changes

- **Academic theme removed** — The custom `academic` theme has been deprecated to avoid confusion with the `academic` style. Supported themes are now `default`, `gaia`, and `uncover` (all built-in Marp themes).  
  The `academic` *style* (`-s academic`) is unaffected and continues to work with any theme.

### Improvements

- **Academic style font size** — The academic style now applies `font-size: 0.95em` globally.  
  Override per-presentation by adding `<style>section { font-size: 1em; }</style>` to any slide.

- **Methodology layout 2-row support** — When 4–6 steps are provided, the methodology layout now arranges them in two rows (3 + remainder) instead of overflowing in a single row.
