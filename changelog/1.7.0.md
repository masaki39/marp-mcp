## What's New in 1.7.0

### External Styles via marp-cli Config

marp-mcp now discovers CSS themes from your existing marp-cli configuration automatically. If a `.marprc.yml` (or `.marprc.json`, `marp.config.js`, `package.json` `marp` field) is found at server start, every CSS file listed under `themeSet` is registered as an MCP style.

**How it works:**

```yaml
# .marprc.yml
themeSet:
  - ./themes/my-brand.css
```

```css
/* themes/my-brand.css */
/* @theme my-brand */
section { background: #f5f5f5; }
```

`my-brand` becomes a valid `-s` argument and appears in `list_themes_and_styles` with `"external": true` and the absolute CSS path under `source`. Built-in style names are protected — any collision is logged and skipped.

External styles reuse the active theme's layouts, so all existing tools (`manage_slide`, `create_presentation`, `batch_manage_slides`, etc.) work without any changes.

### Bug Fix: HTML Export Tests on Node 26

Updated `@marp-team/marp-cli` devDependency to 4.4.0, which resolves a yargs ESM compatibility failure that caused HTML export tests to fail under Node 26.
