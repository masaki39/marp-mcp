## What's Changed

### Bug Fixes

- **Academic style font size reverted** — Removed the `font-size: 0.95em` override added in 1.4.0. Font size now follows the active theme's default. Customize per-presentation with `<style>section { font-size: ... }</style>` if needed.

- **`generate_agenda`: agenda inserted before every section** — Previously the agenda slide was only inserted before the first section. Now an agenda slide is inserted before each section, enabling the progress animation to replay at every section transition.

- **`generate_agenda`: section number duplication fixed** — When a section slide was created with the `number` parameter (rendering `<span class="acad-section-num">...</span>`), the numbered icon added by `generate_agenda` caused a duplicate number to appear. The span is now removed when the numbered icon is added.

- **`add_image_transition`: fullscreen slide now fills the entire slide** — Changed `max-width/max-height: 100%` to `width/height: 100%` on `section.img-fullscreen img`, so the image actually expands to fill the slide rather than staying at its intrinsic size.
