# Icons

Numbered circle icons used by `generate_agenda` (agenda list items and section-slide badges).

Files are named `numeric-{N}-circle-{color}.svg` (`N` = 1–9, `color` = 6-digit hex without `#`) and referenced via:

```
https://raw.githubusercontent.com/masaki39/marp-mcp/main/assets/icons/numeric-{N}-circle-{color}.svg
```

Available colors: `666666` (agenda list), `ffffff` (section slides).
